# Particle Accelerator Design Optimization

This project explores a conceptual redesign of a particle accelerator and detector system with the goal of improving Higgs boson detection efficiency.

## About the Project

Inspired by my experience at Vanderbilt Summer Academy, I researched how particle accelerators and detectors work and designed my own conceptual improvements to increase collision efficiency and enhance particle detection.

## Features

- Overview of particle accelerators and detectors
- Engineering design improvements
- Physics equations and engineering analysis
- Tradeoffs and limitations
- Results and references
